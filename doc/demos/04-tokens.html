1 · 颜色令牌

点击色卡复制变量名与当前十六进制值。语义色（ok / warn / bad / info）跨主题保持一致，保证状态含义稳定。

2 · 间距 · 圆角 · 字号

4px 基准阶梯。Qt 里对应 layout 的 setSpacing / setContentsMargins 与 border-radius。

3 · 按钮

min-height 25px 沿用现有全局 QSS，不撑破既有布局；hover 只做 1px 上浮，桌面端足够克制。

4 · 状态药丸

取代纯文字状态（运行中 / 已停止、就绪 / 未就绪）。带 .live 的圆点有呼吸动画。

⚠️
      
QSS 的能力比 CSS 少，落地时注意：不支持 conic-gradient、backdrop-filter、box-shadow、CSS 变量
           （阴影请改用 QGraphicsDropShadowEffect）。环形仪表与玻璃模糊需在 paintEvent 自绘；
